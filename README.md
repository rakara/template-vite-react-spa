# Vite React SPA Starter

Production-oriented starter for dashboards, admin panels and browser-based business applications.

## Stack

- Vite, React and TypeScript (strict)
- React Router
- Tailwind CSS utilities + CSS Modules for complex component styles
- Supabase Auth and PostgreSQL
- TanStack Query, Zustand and Zod
- Vitest and Playwright
- npm, GitHub Actions and Vercel

## Status

Initial repository bootstrap. See `TASKS.md` for implementation status and `docs/` for architecture, development, deployment, environment and security guidance.

## Quick start

The complete setup instructions will be maintained here as implementation lands. Copy `.env.example` to `.env`, configure a Supabase project, then install dependencies with `npm ci`.

## Scope

Includes real Supabase authentication, protected routing, typed data access and application states. No fake users, mocked API responses, or hard-coded credentials.
