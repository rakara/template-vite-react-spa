# Vite React SPA Starter

Production-oriented starter for dashboards, admin panels and browser-based business applications.

## Stack

Vite, React, strict TypeScript, React Router, Tailwind CSS, Supabase Auth, TanStack Query, Zustand, Zod, Vitest and Vercel.

## Setup

Copy `.env.example` to `.env`, configure Supabase, run `npm install` and `npm run dev`. See `docs/` and `TASKS.md`.

No fake users, mocked API responses or hard-coded credentials are shipped.
